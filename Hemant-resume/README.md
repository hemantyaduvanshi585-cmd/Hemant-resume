## 🚀 About Bhoo Dristi AI
**Bhoo Dristi AI** is an advanced, AI-powered geospatial intelligence platform designed to seamlessly analyze, process, and query complex satellite data using natural language. By bridging the gap between raw remote sensing data and human interaction, the platform enables users to effortlessly extract actionable insights.

---

##  Key Features

* **🤖 Agentic Routing:** Automatically parses queries and routes tasks to specialized pipelines.
* **🛰️ RS-VLM Core:** Fine-tuned with datasets like BigEarthNet.txt for accurate satellite data understanding.
* **⏳ Bi-Temporal Analysis:** Compares multi-date imagery (e.g., 2024 vs. 2026) for change detection and change-VQA.
* **🛰️ Optical-SAR Fusion:** Combines optical spectra with SAR backscatter insights for robust multi-sensor reasoning.
* **🗺️ Evidence-First UI:** Outputs confidence scores, spatial change maps, and an auditable execution trace.
